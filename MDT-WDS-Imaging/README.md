This folder will contain my MDT (Microsoft Deployment Toolkit) and WDS (Windows Deployment Services) imaging lab. I will document how I created a deployment share, imported OS images, added applications and drivers, generated boot media, and deployed Windows 10 to client machines.

- Integrating MDT with Windows Deployment Services (WDS)
- Creating and managing deployment shares
- Importing Windows OS images (WIM files)
- Adding applications, drivers, and task sequences
- Generating LiteTouch boot images (ISO/WIM)
- PXE booting Windows clients
- Automating Windows 10 installation
- Troubleshooting imaging and deployment issues
