# DHCP Lab

## Overview
This folder will contain my DHCP (Dynamic Host Configuration Protocol) lab. I will document how I created DHCP scopes, configured reservations, set DHCP options, and verified automatic IP assignment for Windows clients.

## Skills Demonstrated
- Installing and configuring the DHCP Server role
- Creating IPv4 scopes
- Setting scope ranges and exclusions
- Configuring DHCP options (003 Router, 006 DNS, 015 Domain Name)
- Creating DHCP reservations using MAC addresses
- Managing leases and verifying client IP assignments
- Troubleshooting DHCP issues
